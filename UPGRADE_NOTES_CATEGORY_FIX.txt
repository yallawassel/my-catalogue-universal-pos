WHITEPACK CATALOGUE UPDATE — CATEGORY PHOTOS + PRODUCT VISIBILITY

Included:
1. Admin now has a Category photos panel. Choose a separate image for each category and save it.
2. Category photos are stored in the existing mc-saas-images Supabase Storage bucket.
3. Public catalogue reads mc_saas_categories.image_url and uses that image for the category card. It no longer uses a product photo as category art.
4. Removed the old behavior that hid one product with blank prices in each category. Every active product now appears.
5. Products without a price display “Price on request” and do not show an Add to cart button until a price is entered.
6. SKU is displayed as the SKU reference; barcode is shown separately when SKU is unavailable.

INSTALL:
A. Back up your current GitHub project.
B. In Supabase SQL Editor, run CATEGORY_IMAGES_MIGRATION.sql.
C. Upload/replace the project files from this ZIP in your GitHub repository and push/deploy.
D. Open Admin, refresh, go to Category photos, choose a picture for each category and click Save category photo.
E. Open the public catalogue and hard-refresh (Ctrl+F5). Verify every product appears, including products with blank prices.

NOTES:
- No existing product or category rows are deleted.
- Category images are optional until uploaded; a neutral category illustration is shown as fallback.
- The catalogue only shows active products returned by the existing Supabase product query.
- Test on staging before replacing the live catalogue.
