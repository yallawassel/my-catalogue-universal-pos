# AI models

`u2netp.onnx` — U²-Net (small) salient-object segmentation, used by `ai-cutout.js` to remove photo
backgrounds on the user's own device (free, no AI credits).
Source: U²-Net by Qin et al. (https://github.com/xuebinqin/U-2-Net), Apache License 2.0;
ONNX export distributed by rembg (https://github.com/danielgatis/rembg).
